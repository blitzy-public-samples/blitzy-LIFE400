# Pinned Python dependencies for the LIFE400 modernization documentation build.
# Documentation tooling only: this file declares no runtime dependency of LIFE400, whose platform
# baseline remains ILE COBOL V3R7 · OS/400 V4R2 · IBM AS/400 Model 9406 [README.md:L264] and is
# unchanged by this work.
#
# Install with: python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements-docs.txt
# A virtual environment is required rather than advisable: this host's system Python carries a
# PEP 668 externally-managed marker, so installing against the system interpreter fails with
# "error: externally-managed-environment". This is the sequence README.md documents [README.md:L97].
#
# Both versions are pinned exactly rather than as ranges, because mkdocs-material 9.7.7 warns that
# the next major MkDocs release changes the plugin and theming systems with no migration path.
